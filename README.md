# NEXUS VIDEO 5.0 — Prototype 0.2

واجهة عربية RTL لإدارة مشاريع الأفلام والمسلسلات، وحفظ الشخصيات والمشاهد، وتجهيز prompts سينمائية قابلة للنسخ.

## الميزات الحالية
- تصميم متجاوب للجوال والكمبيوتر.
- إدارة مشاريع مع ملخص القصة والأسلوب ونسبة العرض.
- مكتبة شخصيات تحفظ السمات المرجعية للمساعدة في اتساق المظهر.
- محرر مشاهد وربط كل مشهد بمشروع وشخصية.
- مساعد لبناء مسودة Prompt للمشهد من معلومات المشروع والشخصية.
- كاتب مسلسلات ينشئ ملف تطوير منظمًا وطلبًا جاهزًا لإرساله إلى نموذج لغوي.
- نسخ وصف المشهد، وتصدير ملف تطوير TXT.
- استيراد وتصدير نسخة احتياطية JSON.
- ترحيل تلقائي من مفتاح التخزين المحلي القديم `nexus-video-57-data` إلى مفتاح الإصدار 5.0 عند وجود بيانات قديمة.

## الحدود المعروفة
- الموقع الحالي واجهة ثابتة؛ كاتب المسلسلات يُنشئ Prompt ولا يستدعي Gemini بنفسه.
- توليد الفيديو والصوت ومزامنة الشفاه غير موصولة.
- البيانات محلية في المتصفح ولا تتزامن بين الأجهزة.
- GitHub Pages لا يحمي سر API في الواجهة. لا تضع مفاتيح API في `index.html` أو أي ملف عام.

## النشر
من إعدادات المستودع افتح **Settings → Pages**، واختر **Deploy from a branch** ثم الفرع `main` والمجلد `/(root)`.

## اختبار يدوي بعد النشر
1. أنشئ مشروعًا وشخصية ومشهدًا.
2. اربط المشهد بالمشروع والشخصية واستخدم زر بناء Prompt.
3. حدّث الصفحة وتحقق من بقاء البيانات.
4. صدّر JSON ثم جرّب استيراده في جلسة تجريبية.
5. إذا كانت لديك بيانات محفوظة من الإصدار السابق، تأكد من ظهورها بعد التحديث.

## الخصوصية
لا تدخل أسرارًا أو معلومات حساسة. كل الحفظ الحالي محلي، ولا توجد مزامنة أو مصادقة مستخدم.
