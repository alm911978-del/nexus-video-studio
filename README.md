# NEXUS VIDEO 5.7 — Prototype 0.1

واجهة عربية تجريبية لإدارة مشاريع الأفلام والشخصيات والمشاهد.

## المزايا الحالية
- واجهة عربية RTL متجاوبة مع الجوال.
- إنشاء المشاريع ووصفها وتحديد الأسلوب ونسبة العرض.
- مكتبة مرجعية للشخصيات.
- إضافة المشاهد وربطها بالمشاريع والشخصيات.
- نسخ وصف المشهد.
- استيراد وتصدير بيانات JSON.
- حفظ محلي في المتصفح باستخدام `localStorage`.

## الحدود الحالية
- توليد الفيديو والصوت ومزامنة الشفاه غير موصولة.
- لا يوجد حساب مستخدم أو خادم أو مزامنة بين الأجهزة.
- البيانات محفوظة محليًا في المتصفح؛ صدّر نسخة احتياطية بانتظام.
- هذا مستودع عام، لذا لا تضع مفاتيح API أو كلمات مرور أو بيانات خاصة في الملفات.

## النشر عبر GitHub Pages
1. افتح Settings في المستودع.
2. اختر Pages من القائمة الجانبية.
3. ضمن Build and deployment، اختر Deploy from a branch.
4. اختر الفرع `main` والمجلد `/(root)` ثم اضغط Save.
5. انتظر اكتمال النشر، ثم افتح رابط Pages الذي سيظهر في الصفحة.

## اختبار مقترح
افتح الموقع، أنشئ مشروعًا وشخصية ومشهدًا، ثم حدّث الصفحة وتحقق من بقاء البيانات. جرّب تصدير JSON واستيراده.
